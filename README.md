## 🛠️ Как подключиться (Инструкция за 1 минуту)

### 1. Windows / macOS / Linux
* **Рекомендуемые клиенты**: **Nekoray** / **v2rayN** / **Sing-box**
1. Скопируйте ссылку `hy2://...` выше;
2. В клиенте нажмите `Добавить из буфера обмена` (Import from Clipboard);
3. Выберите сервер `ihavean.app/ru` и включите режим TUN / Системный прокси;
4. Запустите YouTube и проверьте воспроизведение в 4K.

### 2. Android
* **Рекомендуемые клиенты**: **NekoBox** (из GitHub/F-Droid) или **Sing-box** / **Clash Meta for Android**
1. Скопируйте строку `hy2://...` или ссылку на подписку;
2. Нажмите `+` ➔ `Импорт из буфера обмена`;
3. Нажмите кнопку подключения.

### 3. iOS (iPhone / iPad)
* **Рекомендуемые клиенты**: **Shadowrocket** / **Surge** / **Sing-box** / **Streisand**
1. Скопируйте универсальную ссылку на подписку `https://ihavean.app/sub/trial100g?key=...`;
2. В Shadowrocket нажмите `+`, тип выберите `Subscribe` и вставьте ссылку;
3. Либо скопируйте `hy2://...` и откройте Shadowrocket — он сам предложит добавить узел.
